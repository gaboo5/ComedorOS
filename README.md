# ComedorOS

Sistema integral de gestión para comedores universitarios: turnos de personal, pedidos y stock, en una sola plataforma.

## 📋 Descripción

ComedorOS nace de una necesidad real: la gestión diaria del comedor de la UNCuyo, donde coordinar turnos de mozos, pedidos y control de stock a mano resulta ineficiente. Este proyecto busca digitalizar y centralizar esos tres procesos.

## ✨ Funcionalidades

- **Gestión de turnos**: asignación y seguimiento del personal (mozos).
- **Pedidos**: registro y seguimiento de pedidos/atención de mesas.
- **Stock**: control de inventario en tiempo real.
